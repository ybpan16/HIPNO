# HIPNO

This repository contains source code associated with the HIPNO project.

## Repository Status

The repository is currently being prepared for public release. At this stage,
it contains only the components that have been organized, documented, and
reviewed for release.

We are continuing to consolidate, validate, and document the remaining model,
training, evaluation, calibration, and experimental workflows. Additional
components will be added progressively as this work is completed.

The current version should therefore be regarded as a partial code release,
rather than a complete end-to-end reproduction package.
